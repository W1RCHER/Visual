# Визуализатор расписания лицея № 9

Проект Святослава Комарова: карта трёх этажей с нажимаемыми кабинетами, расписание по классам и занятость помещений на выбранный день и время. Просмотр без бронирования и ежедневных замен.

## Запуск

Откройте `расписание/расписание.html` в браузере — приложение работает автономно.

Для разработки из корня репозитория:

```sh
python3 -m http.server 8000
```

- Приложение: http://localhost:8000/расписание/dist/
- Пример интеграции с сайтом: http://localhost:8000/локальная%20интеграция/preview/

В примере есть три входа в расписание: верхнее меню, левая колонка и основное синее меню. Это локальная копия; остальные ссылки возвращают на её главную страницу.

## Структура

- `расписание/dist/` — HTML, JavaScript, данные и векторные планы.
- `расписание/source/` — исходное расписание Excel, занятость Word и подписанные планы.
- `расписание/import_schedule.py` — импорт и сборка автономного HTML.
- `расписание/check_data.py` — проверка целостности данных.
- `расписание/проверить.md` — расхождения и вопросы к исходным данным.
- `локальная интеграция/preview/` — готовый пример в оболочке сайта лицея.
- `локальная интеграция/build_preview.py` — сборка примера из сохранённой публичной страницы; загрузка её ресурсов требует интернета.

## Обновление данных

```sh
python3 -m pip install -r requirements.txt
python3 расписание/import_schedule.py
python3 расписание/check_data.py
python3 'локальная интеграция/build_preview.py'
```
