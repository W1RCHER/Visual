# Локальная проверка интеграции

Откройте preview/index.html в браузере, сохраняя структуру папки preview. Три ссылки «Расписание занятий» открывают preview/schedule.html: верхняя панель, левая колонка под версией для слабовидящих и первый пункт второй строки синего меню.

Используется локальный снимок публичной главной страницы лицея с локальными стилями и изображениями. Остальные ссылки в копии возвращают на главную, поиск отключён. Внешние скрипты, аналитика и сторонний виджет Госуслуг не включены. Это не полная копия всех страниц сайта.

Расписание встроено в отдельный iframe для изоляции стилей. Размер подстраивается под содержимое; при ширине 800–1000 пикселей карта и карточка кабинета располагаются рядом. Базовые данные и правила занятости не изменены. В реальном Nubex возможность сохранения iframe и подключения кода ещё предстоит проверить отдельно.

Проверено в Chrome: все три перехода, возврат на главную, переключение этажей, выбор кабинетов 216 и 311, смена времени и отображение двух записей при расхождении источников. Сайт лицея и репозиторий GitHub не изменены.

Сборка: build_preview.py. Снимки оригинальной страницы и CSS: original.html, original.css. Для обновления прототипа расписания повторно выполните сборку.
