# Интеграция в Nubex

Создана новая страница «Расписание занятий», URL `/ru/schedule/`, documentId 32474, текстовый блок 32475. В основном меню скрыта; три ссылки добавляет скрипт.

`page-content.html` — содержимое текстового блока в режиме «Источник».
`external-javascript.html` — значение «Настройки → Внешний Javascript».
`integration.js` — тот же код без HTML-обёртки.

Приложение с данными сжато gzip и встроено в код. На странице расписания распаковывается средствами браузера и открывается в iframe с sandbox="allow-scripts". Внешний хостинг и API не требуются. CSS приложения изолирован от сайта. Другие страницы получают только три ссылки и их стили.

## Откат

В «Настройки → Внешний Javascript» восстановить `backup-javascript-before.html` (до публикации поле было пустым). Страницу `/ru/schedule/` снять с публикации. Другие исходные страницы и настройки не изменяются.

## Исправление запуска 17 ноября 2026

При наличии ранее сохранённой ссылки с атрибутом data-lyceum-schedule-link скрипт завершался до создания iframe. Общая проверка ссылки заменена проверкой собственного элемента стилей; добавление каждого входа проверяется отдельно. Уже существующий пункт «Расписание занятий» в основном меню не дублируется.

Исправление проверено сначала на локальной странице с существующими ссылками, затем сохранено в Nubex и проверено после перезагрузки рабочего сайта. Этажи: 12, 14 и 17 областей; кабинет 311 во вторник в 09:06; кабинет 216 в понедельник в 12:40; режим класса 11И (6 записей во вторник); фильтр занятых помещений (33 во вторник в 10:00); кнопка текущего времени. Локально также проверены неизвестное время в субботу и помещение без данных. Проверка check_data.py пройдена.

Сторонний виджет Госуслуг всё ещё задерживает загрузку страницы и выдаёт ошибку Widget is not defined. Он не изменялся; эту проблему следует устранять отдельно.
