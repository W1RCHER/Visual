# Интеграция в Nubex

Создана новая страница «Расписание занятий», URL `/ru/schedule/`, documentId 32474, текстовый блок 32475. В основном меню скрыта; три ссылки добавляет скрипт.

`page-content.html` — содержимое текстового блока в режиме «Источник».
`external-javascript.html` — значение «Настройки → Внешний Javascript».
`integration.js` — тот же код без HTML-обёртки.

Приложение с данными сжато gzip и встроено в код. На странице расписания распаковывается средствами браузера и открывается в iframe с sandbox="allow-scripts". Внешний хостинг и API не требуются. CSS приложения изолирован от сайта. Другие страницы получают только три ссылки и их стили.

## Откат

В «Настройки → Внешний Javascript» восстановить `backup-javascript-before.html` (до публикации поле было пустым). Страницу `/ru/schedule/` снять с публикации. Другие исходные страницы и настройки не изменяются.
