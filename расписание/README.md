# Расписание и занятость кабинетов лицея № 9

Локальный прототип. Карта трёх этажей по размеченным пользователем схемам: выбор кабинета, дня и времени, занятость и расписание помещения. Сайт Nubex не изменён. Нет бронирования, учётных записей или ежедневных замен.

Открыть `расписание.html` в браузере: весь прототип находится в одном файле, сервер и интернет не требуются. Альтернатива для разработки — `dist/index.html`; рядом с ним должны находиться `app.js` и `data.js`.

## Данные

- `source/расписание.xlsx` и `source/кабинеты.docx` — неизменённые копии предоставленных файлов.
- `data.json` — занятия, записи занятости Word, временные интервалы, ссылки на исходные ячейки/таблицы и результаты сверки.
- `занятия.csv` — плоская выгрузка занятий, включая исключённые из интерфейса записи ЦДО.
- `сверка.csv` — все замечания по сопоставлению, включая пустые записи Word.
- `сверка.md` — итоги и ограничения сверки.

`import_schedule.py` повторно извлекает данные из копий в `source`, не изменяя их. Требует Python с openpyxl и lxml. Для текущего компьютера доступен комплектный Python Codex. Для другого компьютера используйте своё окружение Python с указанными библиотеками.

## Правила

Excel задаёт предметы, классы и кабинеты. Несколько помещений в одной ячейке сохраняются списком без выдуманного распределения подгрупп. Word добавляет отдельные записи занятости, в том числе начальную школу и занятия без класса. Учитель из Word переносится в урок только при совпадении дня, временного слота, кабинета и класса. При нескольких преподавателях порядок подгрупп не установлен.

ЦДО: исключены занятия с кабинетами 2–7 и субботние курсы робототехники, БПЛА, моделирования, машинного обучения и VR без кабинетов. Эти записи сохранены с `scope: cdo`; Moodle имеет `scope: remote` и не занимает физический кабинет. Точные границы корпуса для иных помещений ещё не подтверждены.

Вторая смена сопоставлена с Word по правилу «номер урока + 7». Это наиболее согласованный вариант по классам и кабинетам, но пока не утверждённое расписание звонков. Нулевой урок соответствует 13:25–14:05, первый — 13:45–14:25. Допустимые пересечения не устраняются. Для седьмого урока II смены в Word нет временного интервала: время оставлено null.

Занятость в момент времени использует начало включительно, конец исключительно: `start <= time < end`. Если Excel и Word расходятся, учитываются обе записи. Если у кабинета в этот день есть занятие без времени, интерфейс не показывает его как уверенно свободный. «Нет занятий» означает отсутствие записей об уроках в этот момент и не гарантирует фактическую доступность.

## Карты этажей

Геометрия в `dist/maps.js` вручную перенесена с трёх подписанных пользователем изображений. Это схематическое расположение, не обмерный чертёж. Оригиналы сохранены в `source/размеченные планы`. `dist/map-references.js` содержит эти же изображения для автономной работы.

Каждое подписанное помещение имеет отдельную нажимаемую область. Цвет показывает состояние на выбранный день и время. Для помещений, отсутствующих в обоих источниках расписания, отображается «Нет данных». Положение кабинетов 222 и 223 на предоставленных схемах не подписано; их записи доступны в режиме занятости кабинетов. У спортзалов общий ресурс «с/з»; данные не разделены по большому и малому залу, поэтому их занятость отдельно не утверждается.

## Последующая интеграция

Для Nubex потребуется отдельно согласовать страницу и подключение кода. Этот прототип ничего не публикует. До публикации подтвердить звонки II смены и разобраться с отмеченными расхождениями.
